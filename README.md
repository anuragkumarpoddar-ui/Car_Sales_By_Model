# Car Sales Analysis Dashboard (Microsoft Excel)

## 📌 Project Overview

The **Car Sales Analysis Dashboard** is an interactive business intelligence project developed using **Microsoft Excel** to analyze and visualize car sales performance. The project transforms raw sales data into meaningful insights through **data cleaning, pivot tables, and dynamic visualizations**, enabling data-driven decision-making.

The primary objective of this project is to evaluate sales trends, identify top-performing car models and dealers, and analyze profitability to support strategic business planning.

---

# 🎯 Project Objectives

* Analyze overall car sales performance and profitability.
* Identify the best-selling car models and their contribution to revenue.
* Understand monthly and yearly sales trends.
* Evaluate dealer performance and regional sales distribution.
* Compare sales volume with profit generation.
* Build an interactive dashboard for quick and effective business insights.

---

# 📊 Dataset Description

The dataset contains transactional sales information with the following key attributes:

| Field         | Description                     |
| ------------- | ------------------------------- |
| Year & Month  | Time-based sales analysis       |
| Date          | Transaction-level sales data    |
| Car Model     | Different vehicle brands/models |
| Dealer ID     | Dealer-wise sales distribution  |
| Quantity Sold | Number of units sold            |
| Profit        | Revenue generated from sales    |

# 📈 Key Findings & Insights

## 🔹 Overall Business Performance

* **Total Units Sold:** 21,597 Cars
* **Total Profit Generated:** ₹2,99,68,866+
* Analysis covers **2 years of sales data** across **5 car models**.

---

## 🔹 Top Performing Car Model

### 🏆 Hudson – Best Selling Model

* Hudson emerged as the highest-selling car model based on total quantity sold.
* Demonstrates strong market demand and customer preference.
* Contributed significantly to overall business performance.

## 🔹 Time-Based Sales Trends
